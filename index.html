ESP32 · WI-FI / BLE / RFID · FIELD TOOLKIT

doomBOX

A compact ESP32 wireless toolkit for security research and RF survey work — Wi-Fi, Bluetooth/BLE, RFID, and drone/RF detection, driven from a two-button OLED console.

Forked from nyanBOX by Nyan Devices, itself built on earlier work by CiferTech.

View on GitHub
01

▸Hardware

The core build — driven from an ESP32, read on a small OLED.

  • MCUESP32 (PlatformIO board: esp32dev)
  • Display0.96″ 128×64 OLED (SSD1306, I²C / U8g2)
  • Controls5 buttons — Up, Down, Center, Left, Right
  • Status LEDNeoPixel / RGB
  • RFIDMFRC522 on SPI (optional)
02

▸Features

Four tool groups, split across the main menu's two columns.

📶 Wi-Fi

  • Access-point / client scanner
  • Deauther
  • Handshake capture
  • Client sniffer
  • Deauth-frame scanner
  • Beacon spam
  • Evil Portal (captive portal)
  • Pineapple detector
  • Pwnagotchi detector & spam

🔵 Bluetooth / BLE

  • BLE scanner
  • BLE advertising inspector
  • doomBOX / nyanBOX detector
  • Flipper Zero, Axon, Meshtastic, MeshCore detectors
  • Bluetooth skimmer detector
  • AirTag detector & spoofer
  • Samsung SmartTag, Tile, Ray-Ban Meta detectors
  • BLE spammer, Swift Pair spam, Sour Apple, Sour Droid, BLE spoofer

📡 Other / RF-related

  • Superscanner
  • Drone detector (Remote ID) & drone spoofer (ODID)
  • Flock Safety detector
  • Device Scout
  • Reaper link — ESP-NOW control of ESP32-Reaper for multi-radio passive survey

🏷️ RFID

  • MFRC522 tools (main menu, right column)
Also on the main menu: a level/XP system, NeoPixel status, display mirroring, and a Snake easter egg (Konami code on About: ↑↑↓↓←→←→←→).

▸Differences from stock nyanBOX

Not carried over

  • Camera detector / deauther
  • Passive 802.11 CSV monitor
  • FindMy / HID beepers
  • KARR
  • iBeacon tools
  • LE gear detector
  • Jam detector
  • Battery pack / enclosure
  • Triple-nRF24 on the same board

doomBOX-specific

  • Focus on onboard Wi-Fi/BLE + OLED (no onboard nRF24)
  • RFID column
  • ESP-NOW Reaper integration for remote multi-radio survey
  • Snake easter egg, level system, legal disclaimer flow

▸System overview

doomBOX runs fully standalone. This table is only relevant if you've also built the optional companion field node.

  • Standalone — doomBOX runs all onboard Wi-Fi / BLE / RFID tools without Reaper.
